AutoFill Admin

Bienvenue

AutoFill Admin remplit vos formulaires administratifs à partir de vos documents. Une seule chose à configurer : votre clé API Anthropic.

  1. Créez une clé sur la console Anthropic (compte + quelques euros de crédit), menu « API Keys » → « Create Key ».
  2. Collez-la ici

La clé reste sur ce PC (stockage local de Chrome). Elle n’est envoyée qu’à api.anthropic.com et n’est plus jamais affichée.

C’est prêt ✔

Pour lancer AutoFill Admin facilement :

  • Épinglez l’icône : cliquez sur la pièce de puzzle en haut à droite de Chrome, puis sur la punaise à côté d’AutoFill Admin.
  • Alt+Maj+A ouvre ce panneau (ou le ramène devant), Alt+Maj+F remplit le formulaire.
  • Pour que le raccourci marche même depuis une autre application : ouvrez les raccourcis et réglez la portée sur « Global ».
  • Ce panneau est une fenêtre à part : placez-le sur votre second écran, il y reste.
